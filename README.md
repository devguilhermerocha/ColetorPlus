# Coletor+ 📦
### Sistema Inteligente de Gestão de Reposição e Inventário

O **Coletor+** é uma solução Android profissional desenvolvida para otimizar processos logísticos de entrada, saída, consulta e auditoria de estoque. Com uma interface moderna baseada em Material Design, o aplicativo oferece fluxos distintos para operadores e administradores, garantindo agilidade e segurança operacional.

---

## 🚀 Funcionalidades Principais

### 👤 Módulo Operacional (Usuário)
Focado na agilidade do dia a dia no armazém ou loja:
- **Consulta de Produtos**: Localização rápida de itens por EAN, exibindo quantidade total e endereços vinculados.
- **Entrada / Endereçamento**: Fluxo guiado para vincular produtos a locais específicos via QR Code.
- **Saída / Desendereçamento**: Remoção de itens de locais, com funcionalidade de limpeza rápida de vaga.
- **Ajuste / Avaria**: Registro de baixas por avaria ou ajustes de inventário com seleção de data de lote.

### 🔑 Módulo Administrativo (Master)
Gestão estratégica e controle total do sistema:
- **Dashboard em Tempo Real**: Visualização de itens críticos e validades próximas através de KPIs intuitivos.
- **Auditoria Operacional**: Log detalhado de todas as ações realizadas pelos usuários (quem, quando e o quê).
- **Gestão de Equipe**: Cadastro, edição e controle de perfis de acesso dos colaboradores.
- **Catálogo de Produtos**: Gerenciamento completo da base de dados de mercadorias.
- **Gestão de Endereços**: Controle de ruas, gôndolas e localizações logísticas.

---

## 🎨 Diferenciais de Interface (UI/UX)

O aplicativo passou por um processo rigoroso de refinamento visual:
- **Navegação Inteligente**: Menu inferior com sistema de cores azul (ativo) e cinza (inativo) para melhor orientação.
- **Padronização Milimétrica**: Todos os títulos, margens e cartões seguem um padrão único, evitando distrações e facilitando o uso prolongado.
- **Scanner Avançado**: Leitor integrado de QR Code e Código de Barras customizado (laser oculto para QR Codes para maior clareza visual).
- **Design Responsivo**: Layouts adaptáveis que garantem uma experiência fluida em diferentes dimensões de smartphones e coletores industriais.
- **Ações Críticas**: Botões de alto impacto (como limpeza de vaga) sinalizados em vermelho sólido para prevenir erros operacionais.

---

## 🛠 Tecnologias Utilizadas

- **Linguagem**: Java (Android Nativo)
- **Arquitetura**: Baseada em Fragments com Navigation Component.
- **Interface**: Google Material Components, ConstraintLayout e ViewBinding.
- **Persistência**: SQLite / Room Database para armazenamento local seguro.
- **Escaneamento**: Integração com bibliotecas de alta performance para leitura de EAN-13, UPC e QR Codes.

---

## 📋 Como Utilizar

1. **Login**: Acesse com sua matrícula e senha cadastrada.
2. **Perfil Master**: Redireciona automaticamente para as ferramentas de gestão.
3. **Perfil Usuário**: Abre as ferramentas de operação de campo.
4. **Sincronia**: Todos os dados são atualizados instantaneamente na base local.
